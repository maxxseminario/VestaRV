RISC-V · From the spec up · TSMC 65 nm

A RISC-V core built from the spec up, carried all the way to silicon.

VestaRV is a from-scratch RV32IMAC + Zba/Zbb/Zbc/Zbs RISC-V core — designed straight from the ISA manual, not forked from anyone's reference. It has been taped out on TSMC 65 nm — one chip in silicon and two more designs signed off and regression-proven, ready for their own tape-outs. And it comes with a chip generator that turns one config file into verified RTL, C headers, linker scripts, and a ~160-page reference manual. Vesta is the Roman hearth; each chip is another fire lit from the same flame.

At a glance

Headline specifications

One core family, scaled from a single microcontroller to an 18-hart teaching chip — every configuration emitted from the same generator and proven by regression.

FeatureWhat VestaRV provides
Base ISARV32I with M (mul/div), A (atomics), C (compressed) and bit-manip Zba / Zbb / Zbc / Zbs. Extensions are generator knobs (misa reflects them).
Harts1 to 18 harts from one RTL source. 5 harts = Castalia (a soft always-on orchestrator on hart 0 plus four hardened rv32iac channel tiles), 18 harts = Argus — both regression-proven end to end.
InterruptsStack-based recursive interrupts plus a PLIC-lite external fabric with atomic claim / complete delivery and per-hart routing.
SynchronizationHardware mutex bank (1-instruction acquire), LR/SC reservations, and cross-hart AMOs made atomic through the shared-bus arbiter.
AcceleratorNPU — a fixed-point neural-network accelerator with a MAC datapath and shared staging RAM, shared across all harts.
ProcessTSMC 65 nm, full RTL-to-GDS flow (synthesis, place-and-route, signoff DRC/LVS).
SiliconOne tape-out in silicon — Myshkin (single-core), fabricated on TSMC 65 nm in Nov 2025. Castalia (5-hart) and Argus (18-hart teaching chip) are signed off and regression-proven, ready to tape out.

The family

Three configurations, one hearth

Each is a different configuration of the same core, taken through the same flow to a signed-off layout. One of the three has been fabricated.

Myshkin

Multicore

Castalia

5 harts Tape-out ready Shared bus + NPU

A five-hart SoC: an always-on soft orchestrator on hart 0 and four hardened rv32iac channel tiles, over a shared boot ROM, hardware mutexes, cross-hart atomics, and a shared NPU behind an arbitrated bus. Signoff-closed and regression-proven — a future tape-out.

Read the technical reference manual
Teaching chip

Argus

18 harts Tape-out ready Tiled P&R

An 18-hart teaching chip built from the same generator — identical tiles, one shared ROM, hardened and assembled as a tiled layout. Signoff-closed and regression-proven — a future tape-out.

Deep dive — how Castalia’s field-powered NFC mode works: the PGOOD boot gate, the harvested-boot ROM path, and whether it closes on harvested energy. Deep dive — how the event fabric lets peripherals run the chip while the CPU sleeps: an 8-channel hardware crossbar that wires events straight to tasks, no interrupt required.
