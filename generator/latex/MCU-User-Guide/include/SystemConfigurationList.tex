\item Chip name: Myshkin
\item Compatible with RISC-V compiler RV32I[M]
\item 32-bit memory bus
\item Contains 32 general purpose dual-port CPU registers
\item Includes a barrel shifter in the ALU to produce fast bit shift operations
\item Includes a fast 32-bit signed integer hardware multiplier in the ALU and allows the use of the [M] compiler extension
\item Includes a medium speed 32-bit signed integer hardware divider and remainder calculator in the ALU
\item Supports maskable hardware interrupts generated by peripheral signals
