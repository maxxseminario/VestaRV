\subsubsection{Transients}\label{sss:pixel-transient}

Figure~\ref{fig:px-cv-voltammogram} is a cyclic-voltammetry sweep at the
\SI{1}{\mega\ohm} electrode: the working-electrode current stays within the
loop's linear region for the entire sweep, unclipped
(Table~\ref{tab:px-cv-stats}). Figure~\ref{fig:px-step-i} is the current
response to a \SI{400}{\milli\volt} step in the commanded reference potential
at the same electrode. \textbf{The edges rail transiently by design}: the
bench exercises the step edge itself, and the current briefly saturates
against the loop's slew-limited transient (Table~\ref{tab:px-step-stats})
before settling to the value the \SI{1}{\mega\ohm} cell impedance sets. Read
the transient extremes as edge behaviour, not a sustained current rating.
