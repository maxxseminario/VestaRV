Three limits on what this section claims. First, the resistance, linearity and
mismatch data are two-terminal measurements of the ladder alone; only noise and
loop stability have been measured with the ladder inside the transimpedance loop
(Section~\ref{sss:tiarprog-noise}), at one electrode and one process corner, and
settling with the real switches is still open. Second, the Monte Carlo is
mismatch-only at \SI{25}{\celsius}; no process-plus-mismatch statistics exist. Third, the bottom code is the block's
weak point, and all three of its symptoms share one root cause: the
\SI{1.65}{\kilo\ohm} closed-switch stack (\(+9.2\,\%\) at \(N=0\)), the
\(1.26\)-LSB drive nonlinearity, and the \(4\times\) larger relative mismatch
spread are all the ten bypass gates in series with a three-unit ladder. Absolute
gain at any code calibrates out against the corner and mismatch spread; if the
bottom code ever needs uncalibrated accuracy, the fix is wider bypass gates, not
more ladder. Integration into \texttt{anatop\_tia} (whose legacy 16-bit
\texttt{tia\_gain} bus becomes these ten control bits) is pending, as is layout.
