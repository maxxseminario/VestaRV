\section{Overview}

The \peripheral{SYSTEM} peripheral groups the chip-level control blocks: the clock tree roots and dividers, the memory block power gates, a CRC16 accumulator and the watchdog timer. Its effects are global (MCLK clocks all harts and SMCLK clocks the peripherals), so by convention only hart 0 reconfigures the clocks, after quiescing the other harts.

\begin{itemize}
	\item Source selection and enables for MCLK and SMCLK (\register{SYSCLKCR}), dividers for both (\register{CLKDIVCR}), and bias control of the two on-chip oscillators (\register{DCO0BIAS}, \register{DCO1BIAS})
	\item Power gates in \register{BLOCKPWR} for the ROM, the per-hart memory blocks and the first four shared RAM banks
	\item CRC16-CDMA2000 accumulator (\register{CRCDATA}, \register{CRCSTATE})
	\item 24-bit watchdog with sixteen timeouts, password-protected control, optional interrupt and hardware reset (\register{WDTCR}, \register{WDTPASS}, \register{WDTSR}, \register{WDTVAL})
	\item One interrupt: watchdog timeout, vector 0
\end{itemize}

Interrupt routing is not managed here: every hart enables peripheral interrupts through its \peripheral{IRQROUTER} row, and the \peripheral{CLINT} vectors are hardwired into every hart. The register slots of the single-core chip's vectored interrupt controller (\register{IRQENx}, \register{IRQPRIx}, \register{IRQCR}) are reserved and read as zero.

\section{Functional description}

\subsection{Clock control} \label{ss:clocks}

The clock tree, its four sources and the clock state at reset and after boot are described in the Reset, clocks and power chapter (Section \ref{s:clocktree}). \register{SYSCLKCR} holds the root selects and the source enables: \bitfield{MCLKSEL} and \bitfield{SMCLKSEL} pick the source of each root, \bitfield{SMCLKOFF} stops SMCLK, \bitfield{HFXTOFF} and \bitfield{LFXTOFF} stop the external sources, and \bitfield{DCO0ON} and \bitfield{DCO1ON} start the on-chip oscillators. A source selected by either root stays enabled regardless of its enable bit, so the running clock cannot be stopped by mistake. \register{CLKDIVCR} divides each root after its multiplexer, and \register{DCO0BIAS} and \register{DCO1BIAS} set the oscillator frequencies. Both root multiplexers are glitch-free, so a source change while running produces no runt pulse.

Because MCLK clocks every hart and SMCLK clocks the peripheral engines, writing \register{SYSCLKCR} or \register{CLKDIVCR} changes the timing of all \NumHartsWord{} harts and every serial peripheral at once. Reducing the MCLK frequency, through the divider, a slower source or a lower DCO bias, is the main lever on dynamic power.

\subsection{Memory block power} \label{ss:system-blockpwr}

\register{BLOCKPWR} gates the supply of the ROM (\bitfield{SYSROMOFF}), the two per-hart memory blocks (\bitfield{SYSRAM0OFF}, \bitfield{SYSRAM1OFF}) and the first four shared RAM banks individually (\bitfield{SYSSHB0OFF} to \bitfield{SYSSHB3OFF}); banks beyond the fourth are permanently powered. A gated block reduces leakage and loses its contents, because the gate disconnects the array's supply rail and there is no retention; an access to a gated block returns undefined data. All blocks power up on at reset, and the contents of a block that has been gated are undefined until written.

\subsection{Hart sleep} \label{ss:sleep}

Each hart can stop its own clock with the \asminline{sleep} instruction, which reduces that hart's dynamic power to zero while the peripherals and the other harts continue. A sleeping hart is woken only by an interrupt (a \peripheral{CLINT} software or timer interrupt, or a peripheral interrupt routed to it) or by reset. On an interrupt the clock is re-enabled for the handler; when every pending interrupt has been serviced the hart returns to sleep, unless a handler executed the \asminline{wake} instruction, in which case the hart stays awake and continues after the \asminline{sleep}. The average power of a duty-cycled hart is its running power scaled by $t_\textrm{on} / (t_\textrm{on} + t_\textrm{off})$.

\subsection{CRC accumulator}

The CRC module computes CRC16-CDMA2000 over a byte sequence: width 16, polynomial \texttt{0xC857}, initial value \texttt{0xFFFF}, no input or output reflection, no output XOR. \register{CRCSTATE} holds the running value and \register{CRCDATA} accepts one byte per write.

\subsection{Watchdog}

The watchdog is a 24-bit counter that increments on every MCLK cycle while \bitfield{SYSWDTEN} is set. \bitfield{SYSWDTCDIV} selects which counter bit, 16 to 31, raises the event on its 0-to-1 transition, so the timeout is $2^{\bitfield{SYSWDTCDIV} + 16}$ MCLK cycles: at 24 MHz from about 2.73 \si{\milli\second} to about 89.5 \si{\second}. On the event, \bitfield{SYSWDTIF} is set; if \bitfield{SYSWDTIE} is set and vector 0 is routed to some hart, the interrupt is delivered through the \peripheral{IRQROUTER} and, if \bitfield{SYSWDTHWRST} is also set, the chip resets after that hart completes the claim. If the interrupt is disabled or unrouted, the chip resets immediately on the event when \bitfield{SYSWDTHWRST} is set.

\register{WDTCR} is write-protected: a write of the unlock password \texttt{\WdtUnlockPassword} to \register{WDTPASS} opens a 64-MCLK-cycle window in which \register{WDTCR} accepts a write, so that a runaway program cannot disable the watchdog by chance. A write of the clear password \texttt{\WdtClearPassword} to \register{WDTPASS} resets the counter to zero. \bitfield{SYSWDTRF} in \register{WDTSR} records that the last reset was caused by the watchdog and survives reset. \register{WDTVAL} reads the counter, or zero while the watchdog is disabled.

\section{Programming}

\subsection{Selecting the clock sources}

\begin{enumerate}
	\item Quiesce the other harts, because the change reaches every hart.
	\item Set \register{SYSCLKCR}.\bitfield{DCO0ON} or \register{SYSCLKCR}.\bitfield{DCO1ON} if a DCO is to be used, and write its bias register.
	\item Write \register{CLKDIVCR}.\bitfield{SYSMCLKDIV} and \register{CLKDIVCR}.\bitfield{SYSSMCLKDIV}.
	\item Write \register{SYSCLKCR}.\bitfield{SMCLKSEL}.
	\item Write \register{SYSCLKCR}.\bitfield{MCLKSEL}.
	\item Set \register{SYSCLKCR}.\bitfield{HFXTOFF} or \register{SYSCLKCR}.\bitfield{LFXTOFF} for any source no longer needed.
\end{enumerate}

\subsection{Computing a CRC}

\begin{enumerate}
	\item Write \texttt{0xFFFF} to \register{CRCSTATE}.
	\item Write each byte, in order, to \register{CRCDATA}.
	\item Read the result from \register{CRCSTATE}.
\end{enumerate}

\subsection{Starting the watchdog}

\begin{enumerate}
	\item Route vector 0 to the servicing hart in its \peripheral{IRQROUTER} row if the interrupt is wanted.
	\item Write \texttt{\WdtUnlockPassword} to \register{WDTPASS}.
	\item Write \register{WDTCR} with \bitfield{SYSWDTCDIV}, \bitfield{SYSWDTIE}, \bitfield{SYSWDTHWRST} and \bitfield{SYSWDTEN} set in the same write, within 64 MCLK cycles of the unlock.
	\item Write \texttt{\WdtClearPassword} to \register{WDTPASS} periodically, within the timeout.
\end{enumerate}

\subsection{Putting a hart to sleep}

\begin{enumerate}
	\item Set a valid stack pointer, because interrupt entry stores to it.
	\item Enable the wake source's vector in the hart's interrupt controller.
	\item Execute \asminline{sleep}.
	\item In the handler, execute \asminline{wake} before returning if the hart is to stay awake.
\end{enumerate}

\section{Usage notes}

\paragraph{Reconfigure the clocks from hart 0 only, with the other harts quiesced.} \register{SYSCLKCR} and \register{CLKDIVCR} change the clock of every hart and every peripheral engine at once.

\paragraph{Keep HFXT running across reset.} Both roots select HFXT at reset; a board that gates the oscillator from a chip-driven pin does not boot.

\paragraph{Select the SMCLK source before using an SMCLK-domain peripheral.} The boot ROM may leave SMCLK on LFXT (32.768 kHz).

\paragraph{Keep the bank in use powered.} A gated shared RAM bank or memory block loses its contents and returns undefined data; track which banks hold live stack or payload data before writing \register{BLOCKPWR}.

\paragraph{Write \register{WDTCR} in one access within the unlock window.} The window closes 64 MCLK cycles after the unlock password; a read-modify-write that straddles it is discarded.

\paragraph{Clear \bitfield{SYSWDTIF} with a 1 in the handler.} The interrupt is a level; with \bitfield{SYSWDTHWRST} set the chip resets after the claim is completed regardless.
