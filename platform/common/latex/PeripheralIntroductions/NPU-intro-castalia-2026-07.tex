\section{Overview}

The \peripheral{NPU} is a fixed-point neural network processing unit built around one multiply-accumulate datapath and a configurable sequencer. One engine provides four datapath modes, selected per computation by \bitfield{NPUMODE}: a fully connected layer, a one-dimensional convolution, a binary XNOR-popcount layer and a general matrix multiply. Operands and results live in the 16 KiB staging RAM at \texttt{0xC000} to \texttt{0xFFFF}, which is shared between the harts and the engine's compute port.

\begin{itemize}
	\item Four datapath modes (\bitfield{NPUMODE}): dense layer, 1-D convolution, XNOR-popcount, GEMM
	\item Q0.24 inputs, Q7.24 weights and accumulator, per-step rounding and saturation
	\item Five activation functions on one hardware sigmoid approximator (\bitfield{NPUACTF}, \bitfield{NPUAEN}): sigmoid, ReLU, tanh, clamp, exponential
	\item Optional bias term per neuron (\bitfield{NPUBEN}); packed input and weight formats (\bitfield{NPUXPK}, \bitfield{NPUWPK})
	\item Three word-index pointers into the staging RAM (\register{NPUIVSAR}, \register{NPUWVSAR}, \register{NPUOVSAR}) and two per-mode configuration words (\register{NPUCFG1}, \register{NPUCFG2})
	\item One interrupt, think-done, vector 120
\end{itemize}

\section{Functional description}

\subsection{Staging RAM ownership}

The staging RAM is one single-port SRAM macro. While \bitfield{NPUTHINK} is set the port belongs to the engine; the multiplexer select is \bitfield{NPUTHINK} re-clocked on the free-running chip clock, so the port changes hands one cycle after a hart's start write lands and one cycle after the engine's completion pulse, and a hart's in-flight access is never cut in half. The hardware does not stop a hart from reaching into the window while the engine owns it: the access completes at the arbiter in the ordinary time and returns or overwrites whatever the RAM is holding for the engine. The rule that no hart touches \texttt{0xC000} to \texttt{0xFFFF} while \bitfield{NPUTHINK} reads 1 is therefore software's, and the poll on \bitfield{NPUTHINK} is the whole of it.

The pointers \register{NPUIVSAR}, \register{NPUWVSAR} and \register{NPUOVSAR} are word indices into that array (byte offset from \texttt{0xC000} divided by 4), not addresses of separate memories. The sequencer trusts its configuration and bounds-checks nothing: a working set larger than the 4096 words, or count fields inconsistent with the staged data, wraps the 12-bit word index and corrupts neighbouring regions without the engine ever hanging.

\subsection{Data formats}

Inputs (dense and convolution inputs, GEMM A elements) are signed Q0.24 in bits 24:0 of a word, representing $[-1, 1)$; bits 31:25 are ignored. Weights (and GEMM B elements) are signed Q7.24, representing $[-128, 128)$. Outputs are Q7.24 unless an activation narrows them. The accumulator is Q7.24 with round-to-nearest and saturation at $\pm 128$ applied at every multiply-accumulate step in the fixed sequencer order, so a long dot product with large coefficients can clip before its end. XNOR mode packs 1-bit operands 32 per word and emits $\pm 1.0$ Q7.24 words.

\subsection{Packed operand formats}

Two bits in \register{NPUCR} halve the staging footprint of a layer at the cost of resolution. With \bitfield{NPUXPK} set, the input vector holds two 16-bit Q0.15 elements per word, element $2i$ in bits 15:0 and element $2i+1$ in bits 31:16, so element $i$ is read from word \register{NPUIVSAR}${} + i/2$; the range stays $[-1, 1)$ and firmware packs by arithmetic-shifting each Q0.24 input right by 9. The output vector is never packed, because outputs are full-width accumulator or activation words, so a layer whose outputs feed the next layer's inputs either leaves \bitfield{NPUXPK} clear or repacks between computations.

With \bitfield{NPUWPK} set, the weight matrix holds two 16-bit Q3.12 weights per word in the same element order as the unpacked layout; only the storage changes, and the element walk of every mode, including the convolution filter-block reload and the GEMM per-row reload, is unchanged. A maximal 256 by 256 layer then needs 8 re-stagings of the 4096-word staging RAM instead of 16. Q3.12 narrows the weight range from $[-128, 128)$ to $[-8, 8)$ and coarsens the resolution from $2^{-24}$ to $2^{-12}$: firmware packs by arithmetic-shifting each Q7.24 weight right by 12 and must saturate first, because a weight outside $[-8, 8)$ has no packed representation and the hardware only ever sees the packed half. The bias weight rides the same stream under the same range. Both bits are ignored in XNOR mode, which already packs 32 one-bit operands per word, and both are latched when \bitfield{NPUTHINK} is set, so a write during a run takes effect at the next run.

\subsection{Datapath modes}

\bitfield{NPUNI} and \bitfield{NPUNN} hold a count minus one and are reinterpreted by each mode, as are \register{NPUCFG1} and \register{NPUCFG2}.

\begin{itemize}
	\item \textbf{Mode 0, dense layer} (reset default): \bitfield{NPUNI} + 1 inputs at \register{NPUIVSAR}, \bitfield{NPUNN} + 1 neurons. The weight matrix at \register{NPUWVSAR} holds one contiguous row per neuron; with \bitfield{NPUBEN} set each row begins with a bias weight multiplied by an implicit input of 1.0. \register{NPUCFG1} and \register{NPUCFG2} are unused.
	\item \textbf{Mode 1, 1-D convolution}: \bitfield{NPUNI} = taps $- 1$, \bitfield{NPUNN} = filters $- 1$. \register{NPUCFG1} packs stride, dilation, input length and channel count; \register{NPUCFG2} holds the output length, which the sequencer trusts, so the padding convention is a firmware decision. Inputs are channel-major, weights filter-major (bias first per filter with \bitfield{NPUBEN}), outputs filter-major.
	\item \textbf{Mode 2, XNOR-popcount}: activations and weights packed 32 per word LSB first. \bitfield{NPUNI} = packed words per neuron $- 1$; the exact bit count $K \le 4096$ is in \register{NPUCFG2} bits 12:0 and the unused tail bits of the last word are masked. A neuron emits $+1.0$ when $2 \cdot \mathrm{popcount}(\mathrm{XNOR}(a, w)) - K$ is at least the signed threshold in \register{NPUCFG1}, else $-1.0$. \bitfield{NPUBEN} and \bitfield{NPUAEN} must be 0.
	\item \textbf{Mode 3, GEMM}: $C = A \times B$ with $A$ ($M \times K$, row-major, Q0.24) at \register{NPUIVSAR}, $B$ ($K \times N$, column-major, Q7.24) at \register{NPUWVSAR}, $C$ ($M \times N$, row-major) at \register{NPUOVSAR}; $K - 1$ in \bitfield{NPUNI}, $N - 1$ in \bitfield{NPUNN}, $M - 1$ in \register{NPUCFG1} bits 7:0. There is no accumulation across runs, so $K$ must fit one run; larger $M$ or $N$ tile by re-pointing the registers. Because $C$ is row-major, a result chains directly as the next layer's $A$. \bitfield{NPUBEN} must be 0.
\end{itemize}

Mode codes 4 to 7 run as mode 0. The mode, counts and activation selection are latched into run shadows when \bitfield{NPUTHINK} is set, so a write during a run takes effect at the next run.

\subsection{Activation functions}

With \bitfield{NPUAEN} set, each output passes through the function selected by \bitfield{NPUACTF} before it is written; with \bitfield{NPUAEN} clear the raw Q7.24 accumulator is written regardless. All five are shift-and-add wrappers around one piecewise-quadratic sigmoid approximator: 0 = sigmoid (Q0.24 in $[0, 1)$, saturating for $|x| \ge 4$); 1 = ReLU (Q7.24; an output at or above 1.0 is not a valid Q0.24 next-layer input); 2 = tanh as $2\sigma(2x) - 1$ (in $[-1, 1)$, saturating for $|x| \ge 2$, a valid next-layer input); 3 = clamp to $[-1, 1)$ (always chains); 4 = exponential as $2\sigma(x)$ (Q1.24 in $[0, 2)$, the per-element scores of a softmax whose sum and normalisation firmware performs; subtracting the maximum logit first maps it to exactly 1.0). Codes 5 to 7 read as sigmoid. XNOR mode ignores the activation path.

\subsection{Run time}

Run time scales with the mode's loop product: a GEMM costs on the order of $5 \cdot M \cdot N \cdot K$ cycles and a convolution $5 \cdot C_{out} \cdot L_{out} \cdot C_{in} \cdot K$, so a full-scope convolution can take hundreds of milliseconds at 24 MHz. XNOR mode is about an order of magnitude cheaper per output, because one fetched word pair carries 32 synapses.

\section{Interrupts and events}

The completion pulse that clears \bitfield{NPUTHINK} also sets the sticky flag \bitfield{NPUTHINKDONE} in \register{NPUSR}; the interrupt is the level of that flag gated by \bitfield{NPUTDIE}, on the free-running clock. \bitfield{NPUTDIE} resets to 0, so polling software is unaffected. \section{Programming}

\subsection{Running one computation}

\begin{enumerate}
	\item Poll \register{NPUCR}.\bitfield{NPUTHINK} until it reads 0.
	\item Stage the operands in the staging RAM in the selected mode's layout.
	\item Write the input word index to \register{NPUIVSAR}.
	\item Write the weight word index to \register{NPUWVSAR}.
	\item Write the output word index to \register{NPUOVSAR}.
	\item Write \register{NPUCFG1} and \register{NPUCFG2} if the mode uses them.
	\item Write \register{NPUCR} with \bitfield{NPUMODE}, \bitfield{NPUNI}, \bitfield{NPUNN}, \bitfield{NPUBEN}, \bitfield{NPUAEN}, \bitfield{NPUACTF} and, for an interrupt, \bitfield{NPUTDIE}.
	\item Set \register{NPUCR}.\bitfield{NPUTHINK}.
	\item Poll \register{NPUCR}.\bitfield{NPUTHINK} until it reads 0, or take vector 120 and write 1 to \register{NPUSR}.\bitfield{NPUTHINKDONE} in the handler.
	\item Read the outputs from the staging RAM at \register{NPUOVSAR}.
\end{enumerate}

\section{Usage notes}

\paragraph{Do not touch the staging RAM while \bitfield{NPUTHINK} reads 1.} The hardware neither blocks nor stalls the access; it returns or corrupts the engine's data.

\paragraph{Check \bitfield{NPUTHINK} from every hart, not only the one that took the interrupt.} The interrupt tells one hart the run has finished; any other hart consults the flag before reading results.

\paragraph{Size the working set yourself.} Nothing in the sequencer checks bounds; an oversized working set wraps the 12-bit index and corrupts its neighbours silently.

\paragraph{Saturate weights to $[-8, 8)$ before packing them.} A Q7.24 weight outside that range has no Q3.12 representation; shifting without saturating wraps it.

\paragraph{Chain layers through Q0.24-valid activations.} ReLU outputs at or above 1.0 are not valid inputs; use tanh, clamp or normalised weights when a result feeds the next layer.

\paragraph{Clear \bitfield{NPUTHINKDONE} with a 1 before completing the interrupt.} Reading \register{NPUSR} does not clear it, and the level re-enters the handler otherwise.
