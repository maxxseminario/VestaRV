\section{Overview}

The \peripheral{I2Cx} peripherals are general-purpose I\textsuperscript{2}C interfaces, each able to act as a bus master or as an addressed slave. Master and slave are driven through separate sets of control and status bits that share one pin pair, so a port can be configured for either role, or for both on a multi-master bus.

\begin{itemize}
	\item Master transmitter and master receiver modes with START, repeated START and STOP generation (\bitfield{I2CMST}, \bitfield{I2CMSP}) and a programmable bus clock divider (\bitfield{I2CMDIV})
	\item Multi-master arbitration: losing the bus releases it and sets \bitfield{I2CMARB}
	\item Slave transmitter and slave receiver modes with a 7-bit address (\register{I2CxAR}), a per-bit address mask (\register{I2CxAMR}) and optional general-call response (\bitfield{I2CGCE})
	\item Optional slave clock stretching (\bitfield{I2CSCS}) through the ACK bit
	\item Separate transmit and receive data registers per role (\register{I2CxMTX}/\register{I2CxMRX}, \register{I2CxSTX}/\register{I2CxSRX})
	\item Thirteen individually maskable interrupt sources, one vector each
\end{itemize}

\section{Functional description}

\subsection{Wire protocol}

Both roles use the same two-wire protocol on \pin{SDAx} and \pin{SCLx}. Both lines are open drain and require external pull-up resistors: a device drives a bit low by pulling the line down and releases it to let the pull-up present a one. Because every device can only pull down, two devices driving at once cannot damage each other, and that is what makes multi-master arbitration and slave clock stretching possible on the same pair of wires.

A transfer is framed by two conditions that are illegal during data: START is a falling edge on \pin{SDAx} while \pin{SCLx} is high, and STOP is a rising edge on \pin{SDAx} while \pin{SCLx} is high. Between them \pin{SDAx} changes only while \pin{SCLx} is low, so every data bit is stable across the whole \pin{SCLx} high period and any receiver may sample it there. After the address byte and after each data byte, the transmitter releases \pin{SDAx} for one clock and the receiver pulls it low for an ACK or leaves it high for a NACK. The address byte carries the 7-bit slave address in its upper bits and the direction in its least significant bit: 0 selects a write (master transmitter), 1 a read (master receiver). A master that changes direction or address without giving up the bus issues a repeated START instead of a STOP.

\subsection{Master operation}

With \bitfield{I2CMEN} set, the port drives \pin{SCLx} at the rate set by \bitfield{I2CMDIV}. Setting \bitfield{I2CMST} in \register{I2CxFCR} sends a START (or a repeated START while the bus is held) followed by the byte in \register{I2CxMTX}; each subsequent write to \register{I2CxMTX} sends one byte, and each received byte lands in \register{I2CxMRX}. \bitfield{I2CMXC} marks the end of each byte: in transmitter mode after the slave's ACK/NACK, in receiver mode before this master sends its own ACK/NACK, so software chooses the acknowledge before the next byte. \bitfield{I2CMNR} reports a NACK from the slave. Setting \bitfield{I2CMSP} sends a STOP. If another master wins the bus during arbitration, the port releases the lines and sets \bitfield{I2CMARB}, because continuing to drive would corrupt the winner's transfer.

\subsection{Slave operation}

With \bitfield{I2CSEN} set, the port compares every address byte against \register{I2CxAR} under the mask in \register{I2CxAMR} (a masked bit matches either value), and against the general-call address when \bitfield{I2CGCE} is set. A match sets \bitfield{I2CSA}, with \bitfield{I2CSTM} reporting the direction. In slave receiver mode each byte lands in \register{I2CxSRX} and sets \bitfield{I2CSXC}; a byte arriving before the previous one was read sets \bitfield{I2CSOVF}. In slave transmitter mode each byte is taken from \register{I2CxSTX}, and \bitfield{I2CSTXE} asks for the next one. With \bitfield{I2CSCS} set, the port holds \pin{SCLx} low through the ACK bit until firmware has serviced the flag, which trades bus latency for lossless flow control on a port whose hart may be busy elsewhere.

\subsection{Clocking}

The bus engine runs on SMCLK, divided by \bitfield{I2CMDIV} to the bus rate; the register interface runs on MCLK, so the registers stay readable with SMCLK stopped. The boot ROM may leave SMCLK on LFXT (32.768 kHz), which would put the bus in the low kilohertz range.

\section{Programming}

\subsection{Initialisation as a master}

\begin{enumerate}
	\item Select the SMCLK source in \register{SYSCLKCR} (Section \ref{ss:clocks}).
	\item Set the \register{PxSEL} bits of the \pin{SDAx} and \pin{SCLx} pins, and their \register{PxAFS} fields if the bus is relocated.
	\item Write \register{I2CxCR}.\bitfield{I2CMDIV} for the bus rate.
	\item Set the interrupt enables required in \register{I2CxCR}.
	\item Set \register{I2CxCR}.\bitfield{I2CMEN}.
\end{enumerate}

\subsection{Initialisation as a slave}

\begin{enumerate}
	\item Select the SMCLK source in \register{SYSCLKCR}.
	\item Set the \register{PxSEL} bits of the \pin{SDAx} and \pin{SCLx} pins.
	\item Write the slave address to \register{I2CxAR} and the mask to \register{I2CxAMR}.
	\item Set \register{I2CxCR}.\bitfield{I2CSCS} if clock stretching is wanted, and \bitfield{I2CGCE} for general-call response.
	\item Set the interrupt enables required in \register{I2CxCR}.
	\item Set \register{I2CxCR}.\bitfield{I2CSEN}.
\end{enumerate}

\subsection{Master write of one byte}

\begin{enumerate}
	\item Write the address byte (address and direction 0) to \register{I2CxMTX}.
	\item Set \register{I2CxFCR}.\bitfield{I2CMST}.
	\item Wait for \bitfield{I2CMXC}; if \bitfield{I2CMNR} is set, abort with a STOP.
	\item Write the data byte to \register{I2CxMTX} and wait for \bitfield{I2CMXC}.
	\item Set \register{I2CxFCR}.\bitfield{I2CMSP}.
\end{enumerate}

The register descriptions in Section \ref{peripheralI2Cx} give the remaining sequences (master read, slave transmit, slave receive) field by field.

\section{Usage notes}

\paragraph{Set the SMCLK source before using the bus.} The bus clock is derived from SMCLK, and the boot-time SMCLK source is a boot-ROM implementation detail.

\paragraph{Choose the acknowledge before the next byte in master receiver mode.} \bitfield{I2CMXC} is raised before the master's ACK/NACK, because the last byte of a read must be answered with a NACK to end the transfer cleanly.

\paragraph{Handle arbitration loss by retrying the whole transfer.} After \bitfield{I2CMARB} the port has released the bus mid-transfer; the winner's transaction must complete before a new START.

\paragraph{Serialize whole transactions between harts.} The arbiter makes each register access atomic but not a transaction; a hart that shares a port claims a mutex around each transfer (Section \ref{ss:multicore-sync}).

\paragraph{Clear every flag with a 1.} Writing 0 to \register{I2CxSR} has no effect; a handler that returns with its flag set is re-entered.
