\section{Overview}

The \peripheral{TIMERx} peripheral is a 32-bit general-purpose timer/counter with a glitch-free clock source multiplexer, three output compare units and two input capture units.

\begin{itemize}
	\item 32-bit counter (\register{TIMxVAL}), readable and writable at any time
	\item Three output compare units (\register{TIMxCMP0} to \register{TIMxCMP2}); units 0 and 1 drive PWM outputs, unit 2 sets the period
	\item Two input capture units (\register{TIMxCAP0}, \register{TIMxCAP1}) with selectable edge
	\item Four clock sources (SMCLK, MCLK, LFXT, HFXT) and a divider from 1 to 32,768
	\item Glitch-free clock source switching while the timer runs
	\item Six interrupts: two capture, three compare, one overflow
	\item Latched register reads for stable values while the counter runs
\end{itemize}

\section{Functional description}

\subsection{Clock source and divider}

\bitfield{SSEL} selects the timer clock from SMCLK, MCLK, LFXT or HFXT. The multiplexer is glitch-free, so the source can be changed while the timer is enabled without a runt pulse reaching the counter; the price is that the timer clock stops for a few cycles of the slower of the two clocks involved while the old source is released and the new one engages. \bitfield{DIV} then divides the selected clock, and \register{TIMxVAL} increments on every rising edge of the divided clock while \bitfield{TEN} is set.

The multiplexer powers up parked on the SMCLK slice and needs three edges of the clock being released before another source can engage. The first source selection after reset therefore waits three SMCLK edges at whatever rate SMCLK has at that moment, because the boot ROM may leave SMCLK on LFXT (32.768 kHz), and in that state the wait is about 92 \si{\micro\second} even when the selected source is MCLK or HFXT.

\subsection{Counting}

Setting \bitfield{TEN} starts the counter from its current value; clearing it holds the value, which is kept until the timer is enabled again, written, or reset. \register{TIMxVAL} can be written at any time, enabled or not, and the new value takes effect immediately. Reads of \register{TIMxVAL} are latched on the falling edge of the memory enable signal, so a read during counting returns one stable sample.

\subsection{Overflow and rollover}

When the counter reaches $2^{32} - 1$ it rolls over to zero on the next clock and sets \bitfield{OVIF}. With \bitfield{CMP2RST} set, the counter instead rolls over to zero on the clock after it equals \register{TIMxCMP2}, which sets the period of the PWM outputs, and \bitfield{CMP2IF} is set at each such rollover while \bitfield{OVIF} is not. The comparison is equality, not greater-or-equal: a counter that is above \register{TIMxCMP2}, because software wrote \register{TIMxVAL} or lowered \register{TIMxCMP2} below the current value, counts on to $2^{32} - 1$ before it wraps. \subsection{Output compare and PWM}

Compare units 0 and 1 each hold a compare value (\register{TIMxCMP0}, \register{TIMxCMP1}) that is compared with \register{TIMxVAL} continuously. The output \pin{TxCMPy} toggles when the counter equals the compare value and again when the counter rolls over, so with \bitfield{CMP2RST} set the pair \register{TIMxCMP2} and \register{TIMxCMPy} sets the period and the duty cycle. \bitfield{CMP0IH} and \bitfield{CMP1IH} select the output level while the counter is below the compare value. \bitfield{CMP0OUT} and \bitfield{CMP1OUT} in \register{TIMxSR} report the current output levels whether or not the pins are in alternate-function mode. \subsection{Input capture}

Capture unit $y$, enabled by \bitfield{CAPyEN}, waits for the edge selected by \bitfield{CAPyFE} (0 = rising, 1 = falling) on \pin{TxCAPy}, then copies \register{TIMxVAL} into \register{TIMxCAPy} and sets \bitfield{CAPyIF}. A capture that arrives while \bitfield{CAPyIF} is still set overwrites \register{TIMxCAPy}, so the flag is cleared as soon as the value has been read. \subsection{Status register}

\register{TIMxSR} holds the two output indicators and the six interrupt flags. It is latched on the falling edge of the memory enable signal, and every flag is write-1-to-clear.

\section{Programming}

\subsection{Initialisation as a PWM generator}

\begin{enumerate}
	\item Select a fast SMCLK source in \register{SYSCLKCR} (Section \ref{ss:clocks}).
	\item Write the period minus one to \register{TIMxCMP2}.
	\item Write the duty value to \register{TIMxCMP0}.
	\item Write 0 to \register{TIMxVAL}.
	\item Set the \register{PxSEL} bit of the \pin{TxCMP0} pin, and its \register{PxAFS} field if the output is relocated.
	\item Write \register{TIMxCR}.\bitfield{SSEL} and \register{TIMxCR}.\bitfield{DIV}.
	\item Set \register{TIMxCR}.\bitfield{CMP2RST} and \register{TIMxCR}.\bitfield{CMP0IH} as required.
	\item Set \register{TIMxCR}.\bitfield{TEN}.
	\item Poll \register{TIMxVAL} until it has changed, because the clock handoff may hold the counter for a few cycles.
\end{enumerate}

\subsection{Initialisation for input capture}

\begin{enumerate}
	\item Clear the \register{PxDIR} bit of the \pin{TxCAPy} pin, and write its \register{PxAFS} field if the input is relocated.
	\item Write \register{TIMxCR}.\bitfield{CAPyFE} for the edge.
	\item Set \register{TIMxCR}.\bitfield{CAPyIE} if an interrupt is wanted, and enable the vector in the hart's \peripheral{IRQROUTER} row.
	\item Set \register{TIMxCR}.\bitfield{CAPyEN}.
	\item Set \register{TIMxCR}.\bitfield{TEN}.
\end{enumerate}

\section{Usage notes}

\paragraph{Select the SMCLK source before the first timer clock selection.} The multiplexer releases its reset slice only after three SMCLK edges, so with SMCLK on LFXT the first selection stalls the timer for about 92 \si{\micro\second}.

\paragraph{Poll \register{TIMxVAL} after enabling.} Two reads immediately after setting \bitfield{TEN} may return the same value while the clock handoff completes; the timer is running once the value has changed.

\paragraph{Do not change \bitfield{CAPyFE} while \bitfield{CAPyEN} is set.} The edge detector can see the change as a capture event.

\paragraph{Keep \register{TIMxVAL} below \register{TIMxCMP2} when \bitfield{CMP2RST} is set.} The rollover fires on equality only; a counter above the compare value runs to $2^{32} - 1$.

\paragraph{Clear each flag with a 1 before returning.} Every flag in \register{TIMxSR} is a level into the interrupt controller.

\paragraph{Own a timer from one hart at a time.} The arbiter serializes register accesses but not sequences; a second hart writing \register{TIMxCR} changes the configuration under the owner.
