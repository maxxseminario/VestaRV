# SDK generated-artifact provenance

These files are **snapshots** (byte copies) of the chip-generator output for the
course chip. They are intentionally COPIES, never symlinks/pointers into
`platform/common/out/` — that directory is overwritten on every `make chip`
(and today it holds the Castalia default build again).

- Source config : `platform/common/config/argus_course.json`
  (the Argus 18-hart config with the NPU restored: `"peripherals": {"npu": true}`)
- Generated by  : `make -C platform/common chip CONFIG=config/argus_course.json`
- Snapshot date : 2026-07-17 (re-snapshot after the generated-header fixes)
- Chip          : Argus (course chip) — 18 harts, 32 mutexes, 128 KiB/8-bank
  shared RAM, NPU present (staging RAM 0xC000–0xFFFF, registers 0x4A00),
  extended flash base 0x40000, ISA rv32imac_zba_zbb_zbs.
- Header fixes carried by this snapshot (2026-07): `MemoryMap.h` is now fully
  C-includable — every padding field has a struct-unique `__unused<N>` name (no
  duplicate members within a struct) and `SPI_FLASH_MEM_ADDRESS` is config-driven
  (`(0x40000)` on argus_course, was hardcoded `(0x01000000)`). Proven with
  `riscv-none-elf-gcc -march=rv32ima -mabi=ilp32 -ffreestanding -fsyntax-only`.

## Files

| snapshot | source in out/ | purpose |
|----------|----------------|---------|
| `MemoryMap.h`  | `out/software/include/MemoryMap.h` | C peripheral/register addresses + bitfields |
| `periph.S`     | `out/software/include/periph.S`    | assembly peripheral address header |
| `memory.x`     | `out/linker-scripts/memory.x`      | linker MEMORY{} regions (reference) |
| `periph.x`     | `out/linker-scripts/periph.x`      | linker peripheral symbol addresses (reference) |
| `ChipConfig.resolved.json` | `config/ChipConfig.resolved.json` | resolved knobs + derived geometry |

## Refreshing

To regenerate after a chip change:

```bash
make -C platform/common chip CONFIG=config/argus_course.json
cp platform/common/out/software/include/MemoryMap.h software/course/sdk/generated/
cp platform/common/out/software/include/periph.S     software/course/sdk/generated/
cp platform/common/out/linker-scripts/memory.x       software/course/sdk/generated/
cp platform/common/out/linker-scripts/periph.x       software/course/sdk/generated/
cp platform/common/config/ChipConfig.resolved.json   software/course/sdk/generated/
make -C platform/common chip     # restore Castalia artifacts in out/
```
