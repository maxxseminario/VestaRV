# PyEmanate Python Modules

- `Chip.py` - Chip configuration loader
- `ForthInterface.py` - Forth UART interface
- `HelperFunctions.py` - Utility functions
- `LZW.py` - Compression for Forth commands
- `ProgramDump.py` - Intel Hex parsing
- `ProgramFlash.py` - Flash programming logic
- `UART.py` - Serial communication
