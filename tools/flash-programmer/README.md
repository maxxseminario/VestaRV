# Raspberry Pi Flash Programmer

This directory contains tools for programming the TI serial flash chip via Raspberry Pi GPIO.

## Hardware Connections

Connect the Raspberry Pi GPIO pins to the flash chip as follows:

| Flash Pin | RPi GPIO | BCM Pin | Function |
|-----------|----------|---------|----------|
| SCK       | GPIO27   | Pin 13  | SPI Clock |
| MISO      | GPIO22   | Pin 15  | Master In Slave Out |
| MOSI      | GPIO23   | Pin 16  | Master Out Slave In |
| CS#       | GPIO4    | Pin 7   | Chip Select (active low) |

## Installation

Install required Python packages on the Raspberry Pi:

```bash
sudo apt-get update
sudo apt-get install python3-rpi.gpio
```

## Usage

### Basic Usage

Program an RCF file to flash starting at address 0x0000:

```bash
sudo python3 flash_programmer.py path/to/program.rcf
```

### Specify Start Address

Program an RCF file to a specific address:

```bash
sudo python3 flash_programmer.py path/to/program.rcf 0x8000
```

### Example with Blinky

```bash
# From the vestarv directory on Raspberry Pi
sudo python3 tools/flash-programmer/flash_programmer.py software/blinky/rcf/xxxxxxxxxxxxblinky.rcf
```

## Flash Programmer Features

- **Automatic Power Management**: Powers on flash chip before programming, powers down after
- **Sector Erase**: Automatically erases required sectors before programming
- **Page Programming**: Efficiently programs 256-byte pages
- **Verification**: Reads back and verifies programmed data
- **Safety**: Leaves all GPIO pins as floating inputs after completion

## Flash Commands Supported

The programmer supports the following TI flash commands:

| Command | Hex  | Description |
|---------|------|-------------|
| Power On | 0xAB | Release from deep power-down |
| Power Down | 0xB9 | Enter deep power-down mode |
| Read Status | 0xD7 | Read status register |
| Read Data | 0x03 | Read data (low frequency) |
| Read Data Fast | 0x0B | Read data (high frequency) |
| Page Program | 0x02 | Program up to 256 bytes |
| Write Enable | 0x06 | Enable write operations |
| Write Disable | 0x04 | Disable write operations |
| Chip Erase | 0xC7 | Erase entire chip |
| Sector Erase | 0x20 | Erase 4KB sector |
| Block Erase | 0xD8 | Erase 64KB block |

## Flash Parameters

- **Page Size**: 256 bytes
- **Sector Size**: 4KB (4096 bytes)
- **Block Size**: 64KB (65536 bytes)
- **Power-On Delay**: 30µs
- **Page Program Time**: ~5ms
- **Sector Erase Time**: ~400ms
- **Chip Erase Time**: ~20s

## RCF File Format

The programmer reads RCF (Raw Configuration Format) files generated by the build system. Each line contains a 32-bit word represented as a binary string (32 ASCII '0' and '1' characters).

Example:
```
00001001000000000000000001101111
00010011000001010110000000010011
00000000000000000000000000000000
```

## Troubleshooting

### Permission Denied

If you get a permission error, run with `sudo`:
```bash
sudo python3 flash_programmer.py program.rcf
```

### GPIO Already in Use

If GPIO pins are in use, reset them:
```bash
sudo python3 -c "import RPi.GPIO as GPIO; GPIO.cleanup()"
```

### Verification Failures

- Check wiring connections
- Ensure flash chip is properly powered
- Verify flash chip is compatible with standard SPI commands
- Try lowering SPI clock speed by adding delays in `spi_transfer_byte()`

## Notes

- The programmer uses bit-banged SPI for maximum control and compatibility
- All SPI pins are left as floating inputs after programming to prevent conflicts
- The script requires root privileges to access GPIO pins
- Compatible with TI serial flash chips that support standard SPI commands
