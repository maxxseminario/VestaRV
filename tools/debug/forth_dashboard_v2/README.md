# Forth Dashboard v2 — Myshkin rv4th debug GUI

Offline browser dashboard (FastAPI + plain JS, port 8060) for the Myshkin rv4th Forth ROM:
terminal, registers, memory, code runner, flash programmer, GPIO, macros, session log.
Runs alongside [v1](../forth_dashboard/README.md). Pi setup: [`../README.md`](../README.md).

```bash
cd tools/debug/forth_dashboard_v2
python3 -m pip install -r requirements.txt
./run.sh --sim                                                      # no hardware
./run.sh --port /dev/ttyAMA0 --listen 0.0.0.0:8060 --reset-pin 17   # Raspberry Pi
python3 -m pytest tests/ -q                                         # tests (sim only)
```

Boot service: `myshkin-dashboard.service` (fix its paths, copy to `/etc/systemd/system/`,
`systemctl enable --now`). `data/registers.json` is generated by `data/gen_registers.py`
from v1's config; never hand-edit it.

Caveats:

- Never send `0 echo`: framing needs the echo and `>` prompt; every command then times out.
- Disable the serial login console, or its echo doubles characters.
- API flash `page` is a page index; byte address = `page × 256`.
- RAM upload uses `!` loops (`mw` is a ROM stub), about 1.3 KB/s. Compressed (mode 2)
  transfers are unsupported.
