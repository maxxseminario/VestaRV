# Inherited riscv-tests suites

`rv32si/`, `rv32uf/`, `rv32ud/`, `hypervisor/`, the `rv64*` directories,
`../../benchmarks/pmp/` and `../../benchmarks/vec-*` come unchanged from upstream
[riscv-tests](https://github.com/riscv-software-src/riscv-tests). They are not
part of any VestaRV regression; do not add them to a test list.
