# hdl/myshkin: frozen single-core snapshot

Myshkin RTL (TSMC 65 nm, November 2025) with five post-tape-out fixes in `periph/UART.vhd`,
`periph/SYSTEM.vhd`, `periph/NPU.vhd`, `vesta/c_dec.vhd` and `vesta/vesta.vhd`, so it is not
what was fabricated. The fabricated RTL is `~/chips/myshkin/hdl/MCU`. Frozen: do not edit; RTL
work goes to [`hdl/common/`](../common/README.md). Chip docs:
[`implementations/asic/myshkin-2025-11/`](../../implementations/asic/myshkin-2025-11/README.md).

| Path | Contents |
|---|---|
| `MCU.vhd`, `MemoryMap.vhd` | Top level and address constants, generated by `platform/myshkin/` |
| `vesta/` | Core: RV32IMAC + Zba/Zbb/Zbc/Zbs, M-mode, up to 83 interrupt vectors |
| `periph/` | GPIO, SPI, UART, I2C, TIMER, SYSTEM, NPU |
| `commune/`, `macros/`, `sim/`, `tb/` | Shared cells, macros, behavioural models, testbenches |

No Bazel target tests this tree: the unit benches and `//opensource_sim:isa_regression`
exercise `hdl/common/`. `//hdl:vhdl_sources` declares its files as build inputs.
